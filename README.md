# 빅데이터분석기사 실기 튜터

Claude Code 또는 Codex에서 이 폴더를 작업 폴더로 열고 아래처럼 요청한다.

> 빅데이터분석기사 실기까지 공부할 수 있는 날이 6일 남았어. 하루 3시간 가능해. 내 실력부터 확인해서 가르쳐줘.

재개할 때는 “내 학습 ID는 study01이야. 지난 수업 이어서 해줘”라고 말한다. 학습 ID는 첫 수업에서 안내한다. 다른 수험생에게 전달할 때는 아래 표의 공용 파일만 전달하면 된다.

| 경로 | 용도 |
|---|---|
| CLAUDE.md | Claude Code 수업 시작 지침 |
| AGENTS.md | Codex에서 같은 수업을 시작하는 지침 |
| tutor/workflow.md | 진단, 일정 산정, 힌트, 채점, 진도 갱신 규칙 |
| tutor/curriculum.md | 시험 형식과 작업형 1·2·3유형 개념 지도 |
| tutor/type1-index.md | 데이터마님 연습문제 120개 개념 색인 |
| learners/README.md | 학습자별 기록 저장·재개 규칙 |
| learners/state.template.json | 신규 학습 기록 틀 |
| learners/<학습ID>/state.json | 수업이 시작되면 생성되는 개인 기록 |

## 구현 현황

- **구성 완료** — 진입 지침, 진단과 일정 산정 규칙, 한 문항씩 진행하는 수업, 3단계 힌트, 채점과 진도 저장 형식, 유형별 개념 지도와 데이터마님 색인을 제공한다.
- **수업 중 생성** — 진단 결과, 개인별 일정, 문항 및 채점 기준, 진행 기록을 AI가 대화 중 작성한다. 다른 수험생의 기록은 본인이 지정한 학습 ID로만 연다.
- **추가 구현 후보** — 독립 실행 앱, 자동 채점기, 로그인, 대시보드, 알림. 현재 버전은 파일 읽기·쓰기 기능이 있는 대화형 에이전트에서 사용한다.
- **학습 자료 접근** — 데이터마님 문제 번호를 참고할 수 있다. 원문 접근 권한이 없으면 같은 개념의 가상 데이터 문제로 진행한다. 공유본에는 구매 계정, 개인 학습 기록, 유료 문제 본문과 정답을 포함하지 않는다.
